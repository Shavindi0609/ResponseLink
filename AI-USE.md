# AI Usage Declaration – ResponseLink

## 1. AI Tools Used

- ChatGPT

## 2. How AI Was Used

ChatGPT was used as an assistance tool during the development of the ResponseLink application.

AI assistance was used for:
- Understanding Spring Boot concepts and project structure.
- Getting guidance on creating REST API endpoints.
- Understanding JPA entities and relationships.
- Getting guidance on Spring Security and role-based access control.
- Understanding exception handling and validation.
- Troubleshooting coding errors and configuration issues.
- Improving project documentation and README content.

## 3. My Contributions

I worked on the implementation of the ResponseLink application, including:

- Setting up the Spring Boot project.
- Creating entity classes and database relationships.
- Implementing repositories, services, and REST controllers.
- Developing incident management functionalities.
- Developing responder registration and management functionalities.
- Implementing responder assignment and removal.
- Implementing incident status updates and workflow validation.
- Implementing incident status audit history.
- Configuring MySQL database connectivity.
- Configuring authentication and role-based access control.
- Handling validation errors and business rule violations.
- Preparing API requests and manually testing endpoints using Postman.

## 4. Testing and Verification

I used Postman to manually test the API endpoints.

The following functionalities were checked:

- Creating incidents.
- Retrieving incident details and incident lists.
- Registering responders.
- Retrieving responder details.
- Assigning responders to incidents.
- Removing responders from incidents.
- Updating incident statuses.
- Retrieving incident audit history.
- Checking invalid status transitions.
- Checking duplicate responder assignments.
- Checking inactive responder assignment restrictions.
- Checking operations that are not allowed for resolved incidents.
- Checking role-based access restrictions.

No automated test suite was implemented as part of my current testing process. The API functionalities were manually verified using Postman.
